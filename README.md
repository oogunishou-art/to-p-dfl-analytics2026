## 🎯 アプリ概要

YouTube 上の試合映像に対して、iPhone の画面収録オーバーレイ機能と
組み合わせてプレーイベントを記録・分析するための PWA（Progressive
Web App）です。

主な機能：
- タッチ操作によるプレーイベント記録
- 選手別・場面別の集計と可視化
- フォルダによる試合単位の管理
- ローカル保存によるオフライン利用
- バックアップ機能
