# to-p-dfl-analytics2026# to-p-analysis2026

バスケットボール プレー分析 PWA（Progressive Web App）  
Basketball Play Analysis PWA

**制作・著作：大國将（Shou Ooguni）**  
🔗 https://oogunishou-art.github.io/to-p-analysis2026/

---

## 📱 アプリ概要

YouTube 上の試合映像に対して、iPhone の画面収録オーバーレイ機能と
組み合わせてプレーイベントを記録・分析するための PWA です。

- 動作環境：モダンブラウザ（iOS Safari / Chrome / Edge）
- 実装：単一 HTML ファイル、外部依存なし
- ホスティング：GitHub Pages
